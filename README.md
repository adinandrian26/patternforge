# PatternForge

PatternForge adalah aplikasi desktop local-first untuk menghasilkan seamless pattern procedural secara reproducible. Repository ini berada pada **FINAL RELEASE** (Phase 5–22 selesai).

## What PatternForge is

Aplikasi desktop (Tauri v2 + Preact) untuk membuat pola seamless prosedural yang deterministik: CREATE → PREVIEW → ADJUST → EXPORT. Semua generation lokal, tanpa akun, tanpa cloud, tanpa AI wajib.

## Feature set

CORE: deterministic seed (uint32 canonical), Mulberry32 (`prng-v1`), pattern generation (`pattern-v1`), Circle/Rectangle/Ellipse/Line/Polygon/Star/Ring/Flower/Wave/Leaf/Sprig (botanical motif: stem + leaves + berries + accent bloom), placement Scatter/Grid/Rows, direction base + range, color system (typed RGBA), palette (1–32 warna), background, scale, rotation (derajat UI ↔ radian core), complexity, jitter, line thickness, opacity range, color order.

RENDER: RGBA raster renderer, seamless rendering (wrapped-center + 9 translated copies), 3×3 / 1×1 preview, pixel validation (toleransi 0), checksum FNV-1a, golden `a319b114` + `473443c3`.

EXPORT: PNG (encoder deterministik tanpa dependensi, stored DEFLATE), JPEG (via `jpeg-js`, quality 1–100 default 90, composited opaque), SVG (vektor asli, 9 copies ter-clip, tanpa script/handlers/URL eksternal), EPS Shutterstock-ready (single tile, Illustrator 8/10 compatible, stroke di-expand, transparansi di-flatten ke sRGB, preset 2000/3000/4000 = 4/9/16MP, 100% prosedural tanpa AI), atomic write (temp + rename) via Tauri fs bila tersedia, fallback browser download, typed errors, cancellation.

PRODUCTIVITY: presets (save/load/duplicate/rename/delete, max 100), history (50 terakhir, timestamp hanya metadata UI), batch sequential (max 100, seed sequence, progress, cancel, failure isolation).

ADVANCED: templates bawaan (17: Minimal, Geometric, Organic, Dots, Lines, Abstract, Grid, Shapes, Monochrome, Colorful, Retro Bloom, Zebra, Brush Dash, Bauhaus Rings, Botanical Sprig, Leaf Toss, Ink Bloom), advanced controls (line thickness 0.5–8, opacity range, color order), optional AI assistant (default mock offline deterministik; OpenAI-compatible opt-in eksplisit, Apply/Cancel, tidak pernah auto-overwrite).

PROJECT: local `.patternforge` JSON (`project-v1`) + palette text import, selalu divalidasi sebelum masuk core.

## Requirements

- Node.js and npm compatible with the installed Vite/Vitest versions (verified: Node 24, npm 11);
- Rust toolchain compatible with Tauri v2 for native validation/packaging (needs MSVC linker; provided by the GitHub Actions runner — see Windows installer).

## Install

```bash
npm install
```

The root `package-lock.json` is generated by npm and should be committed for reproducible workspace installation.

## Generation, preview, export

1. Generator tab: atur seed/primitive/density/scale/rotation/complexity/jitter/thickness/opacity/palette/background → Generate.
2. Preview 1×1/3×3 + zoom/fit; Seamless PASS/FAIL + checksum selalu ditampilkan.
3. Export tab: pilih PNG/JPEG(+quality)/SVG, nama file (kosong = deterministik), Export → dialog native bila tersedia, fallback download.
4. Batch tab: count + start seed + format → Run (sequential), progress, Cancel, hasil per item.
5. Presets/History/Templates di tab Library + History; AI di tab AI (mock default; Apply eksplisit); Project di tab Project (save/load `.patternforge`).

## Security foundation

Local-first. Core tidak memakai network, filesystem, shell, `eval()`, `Function()`, `Math.random()`, `Date.now()`, atau random UUID. Satu-satunya randomness browser adalah Randomize Seed (`crypto.getRandomValues`, adapter UI saja) dan kunci API AI sesi (tidak disimpan, tidak di-log, hanya dipakai saat Analyze eksplisit). SVG output disanitasi (tanpa script/handlers/URL eksternal). Lihat `SECURITY.md`.

## Windows installer (via GitHub Actions)

Native build membutuhkan MSVC linker, sehingga dijalankan di CI:
GitHub → Actions → "Windows native release" → Run workflow. Workflow
menjalankan validasi penuh + `tauri build` (target NSIS) dan mengupload
installer nyata sebagai artifact `patternforge-windows-installer`;
workflow FAIL bila bundle aktif tetapi installer tidak ditemukan.
Ikon deterministik di `apps/desktop/src-tauri/icons/` (resep:
`node scripts/generate-icons.mts`). Lihat `RELEASE.md`.

## Known limitations

- Build Tauri lokal terblokir bila `link.exe` (Visual Studio Build Tools C++) tidak tersedia; gunakan GitHub Actions di atas. FileSink memakai browser download sampai capability fs aktif di build native.
- Remote AI provider membutuhkan koneksi + kredensial pengguna dan update CSP `connect-src`; default mock offline selalu berfungsi.
